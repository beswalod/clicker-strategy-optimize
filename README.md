# clicker-strategy-optimize

Консольный симулятор, который вычисляет оптимальную стратегию покупок построек для достижения цели в **1,000,000** монет за минимальное время.

## Правила, реализованные в симуляторе

- Начальный баланс: `100`
- Начальная добыча: `1` монета/сек
- Начисление происходит каждый тик (1 секунда)
- Покупка происходит **после начисления**
- Стоимость после покупки растёт и округляется **до ближайшего целого** (математическое округление, 0.5 вверх)
- Игра завершается сразу при балансе `>= 1_000_000`

Постройки:

1. Стоимость `10`, доход `+1`, рост цены `+20%`
2. Стоимость `100`, доход `+5`, рост цены `+15%`
3. Стоимость `250`, доход `+10`, рост цены `+10%`

## Запуск

```bash
python3 clicker_optimizer.py
```

## Формат вывода

- Номер шага
- Время с начала (сек)
- Номер покупаемой постройки
- Текущий доход в секунду
- Текущий баланс
- Текущее количество построек `[n1, n2, n3]`

Также выводится финальная строка с фактом достижения цели.

## Пауза

На 100-м шаге симулятор ставится на паузу и просит нажать Enter для продолжения.
Если STDIN недоступен (например, в CI), симулятор продолжит автоматически.
